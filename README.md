# A-Life-Archive

A-Life-Archive is a desktop Obsidian plugin for organizing books, movies, music, travel, games, chapter files, indexes, statistics, and personal timelines with Markdown-based data.

## Licensing and payment

This is a paid, closed-source plugin. Full access requires a valid license. License availability and purchase information are provided through the developer's official sales channels.

## Network access

- Activation and periodic license validation connect to the A-series licensing service. Requests include the license or offline license token, product code, a locally generated device identifier, device label, and platform name.
- Downloading a cover from a URL sends a user-initiated request to that image host.
- Remote Banner images are loaded from the URL configured by the user.
- Search actions open the selected external search provider in the browser.

The plugin does not include client-side telemetry, usage analytics, or advertising.

## Local data and external access

User archive data is stored as Markdown and related files under `A_LifeArchive_Data` in the current vault. The optional “Open in VS Code” action launches a local editor for a user-selected Canvas source file, so this release is desktop-only.

## Main sections

1. Works library
2. Chapter and linked-file workspace
3. Search and index
4. Statistics and timeline
